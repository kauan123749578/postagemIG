Para que serve esta página?

A API da Meta não aceita arquivo direto do seu computador. Ela precisa baixar o vídeo por uma URL pública na internet.

Aqui você sobe os arquivos para o servidor do painel. Cada vídeo ganha uma URL (ex: seu-dominio.com/media/videos/arquivo.mp4) que é usada automaticamente em:

  • Publicar — Reels, Stories e fotos
  • Loop automático — fila de vídeos que roda em sequência
  • Capas — thumbnail dos Reels
